# Sponsorship

If Shinobi saves you time, consider [sponsoring the project on GitHub](https://github.com/sponsors/numbererikson).

## What sponsorship pays for

100% goes to:
1. Dedicated maintenance time (issue triage, PR review, dependency
   updates, release management).
2. Hosted infrastructure for the public demo (Postgres, R2 storage,
   Cloudflare Worker).
3. Free hosted tier for verified open-source projects (apply via email).

## Tiers

These exist on the GitHub Sponsors page; replicating here for transparency.

| Tier | Monthly | What you get |
|---|---|---|
| Coffee | $5 | Knowing the project keeps maintained. README mention if you want. |
| Backer | $20 | All of above + priority issue triage flag on issues you open. |
| Sustaining | $100 | All of above + a quarterly 30-min office hours call (group session, capped at 8 participants/quarter). |
| Corporate | $500 | All of above + your logo on the README and marketing site sponsor section + named in the launch screencast credits. |

One-time donations are also welcome — `Buy Me a Coffee` and others get
linked when configured.

## No paywalled features

The self-hosted version of Shinobi will always have feature parity
with the hosted SaaS. Sponsorship buys *maintenance*, not access.

The hosted SaaS subscription buys *convenience* (we run it for you).
Different value props, no overlap.

## What sponsorship is NOT

- Not a way to influence the roadmap. Roadmap items come from real
  user needs (yours included if you open issues). Sponsorship doesn't
  jump the queue — but it does buy maintainer attention to your issues
  via the priority flag.
- Not a guarantee of support response time. Use the Pro plan for that.
- Not a commercial license — Shinobi is MIT, you can already use it
  for anything.

## How to apply for the free OSS-project tier

Email contact@shinobi-apps.hr with:
- The repo URL
- Brief description of the project
- How you'd use Shinobi in your workflow

We'll respond within 5 business days. The grant is 12 months of the
Team tier, renewable.
