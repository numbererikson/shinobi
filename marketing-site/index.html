One task list your agents actually share.

Shinobi is a local SQLite + MCP task spine. Claude Code, Cursor, and your custom agents all read the same project, log the same decisions, and respect the same dead-ends — across sessions, across machines, across the room from your phone.

What it does

Shared task spine

Every AI agent claims tasks, marks them complete, and sees the others' progress through one MCP server. No more "did Cursor already do this?"

Decision log

"We picked Postgres over MongoDB because…" lives in the project memory. Next session's agent reads it before suggesting MongoDB again.

Dead-ends ledger

What you've already tried and ruled out. Agents check it before proposing the same broken approach for the third time.

Mobile approvals

Agent hits a fork? request_approval pushes a notification to your phone with action buttons. Reply from the beach.

Voice capture

Talk into the dashboard PWA, get a transcript + auto-extracted decisions. Or upload a meeting recording and Shinobi drafts decisions for review.

Multi-agent real-time

Two laptops, two agents, one workspace: the Cloudflare Worker relay broadcasts sync events. Whoever pushes, everyone pulls within ~1.5s.

Install

Shinobi is a Node CLI. Works on macOS, Linux, and Windows. Zero cloud accounts required for the local version.

# 1. Install
npm install -g github:numbererikson/shinobi

# 2. Bootstrap (creates ~/.shinobi/ and drops .mcp.json into the current directory)
cd /your/project
shinobi init

# 3. Start the dashboard
shinobi dashboard
# → http://localhost:8765

# 4. Restart your AI client. Claude Code / Cursor / Claude Desktop will see
# the new tools via the .mcp.json that init dropped.

See the README for sync setup, mobile push, voice capture, and the rest.
