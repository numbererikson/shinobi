# Shinobi for VS Code

Status bar + sidebar + commands that talk to your local
[Shinobi](https://github.com/numbererikson/shinobi) dashboard. Keep one
in-progress task visible at all times, claim/complete tasks without leaving
the editor, and browse open decisions + dead-ends from the activity bar.

## Requirements

- Shinobi installed globally: `npm install -g github:numbererikson/shinobi`
- Dashboard running: `shinobi dashboard` (default `http://127.0.0.1:8765`)

## Configuration

Open Settings → Extensions → Shinobi:

| Setting | Default | Notes |
|---|---|---|
| `shinobi.dashboardUrl` | `http://127.0.0.1:8765` | Local or tunneled dashboard URL |
| `shinobi.token` | `""` | Required only if dashboard auth is forced on |
| `shinobi.activeProjectId` | `0` | Set via `Shinobi: Pick Active Project` |
| `shinobi.pollSeconds` | `5` | Status bar / tree refresh interval |

## Commands

- **Shinobi: Open Dashboard** — opens active project in the browser
- **Shinobi: Pick Active Project...** — choose which project this VS Code window tracks
- **Shinobi: Claim Task...** — quick-pick a `todo` task → flips to `in_progress`
- **Shinobi: Complete Active Task** — closes the latest in-progress task
- **Shinobi: Log Decision...** — opens the decisions view in the dashboard (in-editor flow coming in a later release)
- **Shinobi: Refresh** — pull latest snapshot now

## Status bar

Shows the title of your most recently claimed in-progress task. Click it to
open the project page in the dashboard. If multiple tasks are in progress,
the tooltip notes how many.

## Sidebar

Activity bar → target icon → three views:
- **Tasks** — grouped by status, click an item to open it in the dashboard
- **Recent Decisions** — open decisions (status: open / fix_now / fix_later)
- **Dead Ends** — things you've already tried and ruled out for this project

## Build from source

```sh
cd vscode-extension
npm install
npm run build
# Package a .vsix for VS Code:
npx vsce package
# Package a separate Cursor-flavoured .vsix (different display name + publisher
# slot so it does not collide on the Cursor marketplace listing):
npm run package:cursor
```

## Install in VS Code

⌃⇧P → "Extensions: Install from VSIX..." → pick `shinobi-X.Y.Z.vsix`.

## Install in Cursor

Cursor is a VS Code fork with a fully compatible extension API, so the same
extension code ships under a separate manifest.

⌃⇧P → "Extensions: Install from VSIX..." → pick `shinobi-cursor-X.Y.Z.vsix`
(generated by `npm run package:cursor`).

The extension surfaces the same status bar, sidebar, and commands. See
[`../docs/cursor-quirks.md`](../docs/cursor-quirks.md) for any Cursor-specific
gotchas discovered along the way.
